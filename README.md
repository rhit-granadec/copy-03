# CSSE463 Term Project: Recognizing and Counting Cards

This repository contains our full CSSE463 term project work for image-based blackjack card recognition and strategy assistance.

The demo application is in `BlackjackYOLODemo/`, and the repository root contains model training notebooks, dataset artifacts, and pipeline experiments.

## Project Summary

The final system is a real-time blackjack assistant that:
- Detects cards from game screenshots using YOLO.
- Optionally uses a two-stage YOLO -> ResNet18 pipeline for improved classification.
- Computes recommended actions using Blackjack Basic Strategy.
- Tracks Hi-Lo running/true count and suggests bet sizing.
- Logs performance for evaluation (per-card stats and precision-recall curves).

## Python Environment (Shared)

This codebase uses one shared virtual environment at:
- `./.venv`

The demo in `BlackjackYOLODemo/` uses this same environment (no separate demo
venv is required).

Setup/activate from the repository root:

```bash
cd 03
python -m venv .venv
source .venv/bin/activate
pip install -r BlackjackYOLODemo/requirements.txt
```

If `.venv` already exists, only run:

```bash
cd 03
source .venv/bin/activate
```

## Running the Demo

The runnable submission target is:
- `BlackjackYOLODemo/app.py`

Quick start:

```bash
cd 03
source .venv/bin/activate
cd BlackjackYOLODemo
python app.py
```

Then open `http://localhost:5001`.

Optional modes:

```bash
python app.py --pipeline      # YOLO + ResNet18
python app.py --debug         # saves debug frames
python app.py --pipeline --debug
```

## Reproducibility Sequence (Data Dependencies)

Run these steps in order so notebooks and demo paths resolve correctly.

1. Activate the shared environment.
```bash
cd 03
source .venv/bin/activate
```

2. Verify YOLO dataset layout exists (required by YOLO and CNN data-prep notebooks).
```bash
cd 03
ls train/images train/labels valid/images valid/labels test/images test/labels
```

3. Train YOLO detector in `YOLO_model_1.ipynb`.
: This notebook trains from `data.yaml` using `yolov5nu.pt` and writes outputs under `runs/detect/train26/`.
: Expected artifact: `./runs/detect/train26/weights/best.pt`.

4. Build CNN crop dataset with `make_cnn_dataset_2.ipynb`.
: Notebook writes crops to `./cnn_dataset` using `train/`, `valid/`, `test` labels/images.
: For the current pipeline, that generated dataset is used as `cnn_dataset_2` (renamed copy).

5. Ensure CNN dataset path expected by training notebook exists.
```bash
cd 03
mv cnn_dataset cnn_dataset_2
```
: If `cnn_dataset_2` already exists, keep it and skip rename.

6. Train CNN classifier in `resnet1.ipynb`.
: This notebook loads `cnn_dataset_2` and saves:
: `./cnn_resnet18_224x224_3.pt`.

7. Run combined pipeline checks in `pipeline.ipynb` (optional validation step).
: It references:
: `./runs/detect/train26/weights/best.pt`
: and `cnn_resnet18_224x224_3.pt`.

8. Copy best trained models into demo model paths.
```bash
cd 03
cp runs/detect/train26/weights/best.pt BlackjackYOLODemo/models/best.pt
cp cnn_resnet18_224x224_3.pt BlackjackYOLODemo/models/cnn_resnet18_224x224.pt
```

9. Run demo from the shared environment.
```bash
cd 03/BlackjackYOLODemo
python app.py
```
: Optional pipeline mode:
```bash
python app.py --pipeline
```

## Training Outputs (`runs/`)

`./runs` stores Ultralytics output folders:
- `runs/detect/train*`: training runs (checkpoints, args, loss/metric plots,
  confusion matrices, sample train/val predictions).
- `runs/detect/val*`: standalone validation runs.
- `runs/detect/predict*`: prediction/inference output runs.

Current contents include:
- 46 `train*` runs
- 19 `val*` runs
- 14 `predict*` runs

Best YOLO model path used for this project:
- `./runs/detect/train26/weights/best.pt`

Key artifacts in `train26/` include:
- `weights/best.pt`, `weights/last.pt`
- `results.csv`, `results.png`
- `confusion_matrix.png`, `confusion_matrix_normalized.png`
- `BoxF1_curve.png`, `BoxPR_curve.png`, `BoxP_curve.png`, `BoxR_curve.png`
- `args.yaml` and sample `train_batch*` / `val_batch*_pred.jpg` outputs
